# こくごで遊ぼう

小学生（1〜6年生）の国語を、遊びながら覚えるスマホ・タブレット向けアプリです。ホーム画面の上で学年を選べます（記録は学年ごとに別々）。

- 2〜6年生：その学年の漢字（学年別漢字配当表どおり、全1026字）と前の学年の復習、熟語・送りがな、文のきまり、ことわざ・慣用句・故事成語・四字熟語、ローマ字

- ひらがな・カタカナ（46字ずつ）、1年生で習う漢字80字
- ことば遊び（反対ことば・なかまはずれ・しりとり）
- 文づくり（は・を・へ、わ・お・え、ことばのならべかえ）
- 指でなぞる書き取り、問題の読み上げ
- キャラ育成（8段階に進化）、いきもの図鑑・文字図鑑、着せかえのおみせ、毎日スタンプ

## 遊び方

1. iPhone・iPad の Safari でアプリのページを開く
2. 共有ボタン →「ホーム画面に追加」
3. ホーム画面のアイコンから起動

データはその端末の中だけに保存されます。
